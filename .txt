The error you're seeing happens because pip is trying to compile pandas (and potentially other packages) from source code instead of using a pre-compiled binary "wheel". This typically happens if the strict version pinned in requirements.txt (like pandas==2.2.2) doesn't have a pre-compiled binary available for your specific Python version (e.g., if you're using a very recent version of Python).

To fix this, I have just updated the requirements.txt file to change the strict version pinning (==) to minimum version requirements (>=). This will allow pip to download the latest available pre-compiled wheels for your Python version and avoid the need for Microsoft Visual C++ Build Tools.

Please try running the commands again in this order:

1. Install Dependencies

powershell
.\venv\Scripts\pip.exe install -r requirements.txt
2. Download and Sample Datasets

powershell
.\venv\Scripts\python.exe download_datasets.py
.\venv\Scripts\python.exe sample_datasets.py
3. Run Tests to Verify

powershell
